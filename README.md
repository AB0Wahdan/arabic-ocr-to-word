# 📄 Arabic OCR to Word

> Convert scanned Arabic/English documents into formatted Word files

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![OCR](https://img.shields.io/badge/OCR-1f6feb?style=flat-square) ![python-docx](https://img.shields.io/badge/python--docx-1f6feb?style=flat-square)

## 📌 Overview
A Windows desktop app that takes scanned PDFs and images, runs OCR tuned for Arabic and English, and outputs editable, formatted Word documents with right-to-left layout preserved.

## ✨ Features
- Arabic + English OCR
- PDF and image input
- Formatted .docx output with RTL support
- Batch processing

## 🛠️ Tech Stack
Python, OCR, python-docx

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python app.py
```
